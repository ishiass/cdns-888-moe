# cdns-888-moe
一个cloudflare优选域名 ǁ  a cloudflare preferred domain


## cdns.888.moe  个人维护的三网优选域名，优选其他的优选。
all.txt中是网络搜集到的一些优选域名，带有-1034标识的意味着免费计划的域名不能用workers优选，其他的优选方式未知
usable.txt中是去掉了目前测试出带有-1034标识的域名，暂未完成全部的测试
ct.txt、cu.txt、cmcc.txt、分别对应着当前电信、联通、移动的优选池中的域名  * 每个线路优选两个
default.txt中则是默认线路 * 优选3个  ** 当ct、cu、cmcc线路都无可用地址时会自动切换到默认线路
